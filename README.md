# Поиск автозапчастей Favorit Parts

React + Redux приложение для двухэтапного поиска производителей, аналогов и складских предложений по артикулу. [Техническое задание](TZ.md) составлено по [документации API Favorit Parts](https://lk.favorit-parts.ru/static/wsprice.pdf).

## Запуск

Требуется Node.js 22 или новее и действующий ключ покупателя Favorit Parts.

```bash
npm install
cp .env.example .env
```

Замените `your_customer_key` в `.env` на свой ключ. Файл `.env` исключён из Git.

```bash
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://127.0.0.1:5173`). Команда запускает React и серверный прокси.

Для сборки и запуска готового приложения:

```bash
npm run build
npm start
```

Адрес готового приложения: `http://localhost:3001`.

## Проверка

```bash
npm test
npm run build
```

## Как работает API

- Первый запрос: `GET /api/search?number=...` → сервер передаёт `key` и `number` в Favorit Parts.
- Второй запрос: `GET /api/search?number=...&brand=...` → сервер добавляет `analogues=on`.
- Цена и остаток берутся из `warehouses.price` и `warehouses.stock`. Если складского предложения нет, цена не показывается.

Документированный адрес Favorit Parts использует HTTP. При развёртывании серверный прокси должен работать в доверенной сети; ключ передаётся внешнему сервису по протоколу, указанному в его документации. Для публичного размещения приложения настройте HTTPS перед сервером приложения.
